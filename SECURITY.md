# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

**Email:** hello@aibomstd.com
**Response time:** 48 hours
**Disclosure timeline:** 90 days coordinated

Please include in your report:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix if available

We take security seriously.
aibomstd is a security tool —
our own security must be exemplary.

## What qualifies

- Schema validation bypass
- Incorrect risk scoring logic
- Data exposure in output files
- Supply chain vulnerabilities
  in our dependencies
- CI pipeline security issues
- Incorrect compliance gap detection

## What does not qualify

- Issues in example JSON files
  (these contain fictional data only)
- Theoretical attacks without
  proof of concept
- Issues in third-party tools
  we do not control

## Our commitment

We will acknowledge your report
within 48 hours, provide a timeline
within 5 days, and credit researchers
who report valid vulnerabilities
(unless they prefer anonymity).
